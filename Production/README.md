# Production outputs

This directory contains Gerber and drill outputs generated from the current kiku PCB design. They are retained as **prototype/reference manufacturing outputs** for reproducibility and review.

They are **not a production-approved fabrication release**. The current Rev-A hardware still has unresolved power/USB-C and physical qualification items documented in [`../Firmware/RELEASE_CHECKLIST.md`](../Firmware/RELEASE_CHECKLIST.md). Resolve and sign off those blockers on the intended PCB/BOM revision before ordering production hardware from these files.

The historical `Walkman - Blobject` filenames are retained to match the KiCad project and existing generated-output workflow.
